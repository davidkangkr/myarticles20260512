커뮤니티 설계 청사진 v1.0

환자 가족을 위한
용도 변경 약물 정보 플랫폼

팀 주도, 소규모 시작, 지속 가능한 보상 구조 우선 — 이 세 가지 제약을 핵심 설계 원칙으로 삼습니다.

설계 원칙 0 — 가장 중요한 질문부터
왜 보호자·가족인가 — 이것이 모든 설계를 바꿉니다
정보 탐색 주체
환자보다 보호자가 더 적극적으로 검색
심리 상태
환자: 지침·지쳐 있음
보호자: 불안·행동 욕구
결정 구조
최종 결정은 환자
정보 수집은 보호자
커뮤니티 행동
보호자가 댓글·공유·재방문을 더 많이 함
설계 함의: 정보의 "번역" 레이어가 핵심입니다
보호자는 논문을 읽을 시간도, 의학 지식도 부족합니다. 하지만 판단은 해야 합니다. 따라서 이 플랫폼의 핵심 가치는 "복잡한 임상 정보를 가족이 이해할 수 있는 언어로 번역하는 것"입니다. AI가 이 역할을 담당합니다.
설계 원칙 1
구조: 게시글이 아닌 데이터베이스로
사용자 입력
구조화된 경험 기록 — "후기"가 아닌 "케이스"
자유 서술 대신 표준 입력 폼으로 수집합니다. 암종, 병기, 사용 약물, 용량, 병용 치료, 기간, 관찰된 변화, 부작용을 각각 필드로 받습니다. 게시글처럼 시간 속에 매몰되지 않습니다.
암종병기약물명 + 용량병용 여부기간관찰된 변화부작용현재 상태
AI 처리
AI가 케이스를 자동 분류·요약·검증
입력된 케이스를 AI가 읽고 유사 케이스 군집화, 관련 논문 연결, 허위·위험 정보 플래그 지정을 자동 수행합니다. 운영팀이 일일이 검토하지 않아도 됩니다. 이것이 자원봉사 의존을 끊는 핵심입니다.
유사 케이스 묶기논문 자동 연결위험 정보 플래그요약 생성
가족 출력
보호자가 실제로 쓸 수 있는 형태로 제공
"우리 엄마와 비슷한 케이스 12건"처럼 필터링된 결과를 보여줍니다. 전문 용어는 AI가 쉬운 말로 번역하고, 담당의와 상담할 때 쓸 수 있는 질문 목록도 자동 생성합니다.
유사 케이스 필터용어 번역의사 상담용 질문 생성프로토콜 요약
설계 원칙 2
거버넌스: 매니저 독재를 구조적으로 불가능하게
역할 분리
자
의학 자문단 (Medical Advisory)
의사·약사·연구자 2~3인. 콘텐츠 위험도 판정 최종 권한. 무급이지만 논문 공동 저자 자격 제공으로 인센티브 설계.
팀
운영팀 (Core Team)
플랫폼 운영, 커뮤니티 관리, 비즈니스 개발. 명확한 보상 구조. 강퇴 권한은 정해진 규칙 기반으로만 작동 — 개인 재량 불가.
기
경험자 서포터 (Verified Contributor)
6개월 이상 케이스를 공유한 회원에게 부여. 신규 가입자 온보딩 지원. 플랫폼 수익 일부로 소정의 크레딧 제공.
원
핵심 원칙: 어떤 단일 주체도 단독으로 콘텐츠를 삭제하거나 회원을 강퇴할 수 없음
2인 이상 합의 또는 명문화된 규칙 위반 시에만 조치 가능. 이 규칙 자체는 공개 문서로 고정됩니다.
설계 원칙 3 — 가장 중요
수익 모델: 자원봉사 없이 돌아가는 구조
단계별 수익화
1
1단계: 프리미엄 정보 접근 (월 구독)
기본 케이스 검색은 무료. AI 기반 유사 케이스 분석, 의사 상담용 자료 자동 생성, 프로토콜 비교표는 월 구독(₩9,900~19,900). 가족이 환자를 위해 기꺼이 지불하는 영역입니다.
2
2단계: 연구 기관과의 데이터 파트너십
익명화된 케이스 데이터를 대학 연구팀·임상시험 기관에 제공. PatientsLikeMe가 증명한 모델. 회원 동의 기반, 데이터 수익의 30%는 커뮤니티 운영비로 환원.
3
3단계: 통합 기능 의료 상담 연결 (원격진료)
플랫폼 내에서 통합 기능 의학 전문의와 상담 예약 연결. 소개 수수료 모델. 무분별한 약 권고가 아닌 의료인과의 연결로 안전성 확보.
핵심 인사이트: "보호자 지갑"은 열려 있습니다
암 환자 가족은 이미 정보 비용에 돈을 씁니다. 유튜브 프리미엄, 책 구매, 사설 상담 등. 문제는 신뢰할 수 있는 곳이 없다는 것입니다. 월 1~2만 원의 구독은 신뢰와 구조화된 정보를 제공한다면 충분히 지불 의사가 있는 금액입니다.
